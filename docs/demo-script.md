# Ten-minute Demo Script

1. Explain the original requirements and the deliberately limited MVP scope.
2. Show the feature/package structure and dependency direction.
3. Open Swagger UI and authenticate as the bootstrap platform admin.
4. Create a tenant and tenant administrator.
5. Enable email, create a template, and submit an idempotent recipient batch.
6. Show the batch, delivery report, rendered snapshot, attempt, and event timeline.
7. Explain the bounded worker pool, rotating tenant round robin, token bucket, retry formula, and provider idempotency receipt.
8. Show the Flyway schema and explain why attempts and events are separate.
9. Run the tests and describe H2 versus PostgreSQL usage.
10. Close with the explicitly deferred enhancements.
