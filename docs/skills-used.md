# Skills used during development

Codex's `skill-creator` skill was used to create the reusable local
`spring-notification-architecture` skill. It captures the project's feature boundaries,
tenant-isolation requirements, delivery state-machine/audit invariants, bounded dispatch
rules, and deterministic test expectations for future architecture changes.

The original backend implementation was performed directly with workspace inspection,
file-editing, and Gradle verification. No external AI service, code generator, or reusable
application template was used.
